**Scope note (mandatory).** Every P05 accuracy is legacy. The cross-validation is window-level `StratifiedKFold(5, shuffle=True, random_state=42)` (R1, PF-01), so windows of one trial sit in both training and test folds and the CV is **leaky**. Sub-bands are filtered on each 1 s window (R3, PF-14). Features use `fs = 250` on 256 Hz recordings (PF-04). The reported "2.0 s smoothed" value uses the legacy `i % 5` reset on the clean array, which is misaligned after a rejected window (R8, PF-02). **None of the P05 numbers is comparable with R-6** (`mas/04_REFERENCE_RESULTS.md`, R-6 at lines 76–80: grouped CV by trial, two-tier gate) [4]. R-3 and R-5 appear here as reference targets, not as results of an equal protocol.

## 1. What this phase reproduces

The original project's feature-extractor and model stage (roadmap P05 "Origin": PSD, FBCCA and FBCSP extraction with quality masking; a 5-fold CV benchmark suite with confusion-matrix diagnostics; the hybrid FBCSP+FBCCA pipeline on one subject at 95.43 % smoothed CV) [1]. The phase asks whether the three extractors, the six feature spaces and the ten-model suite, run under the legacy protocol, reproduce R-3 on S03 (FBCSP m=1 + FBCCA → Shrinkage-LDA: 90.36 % at 1.0 s, 95.43 % at 2.0 s smoothed, 197 clean and 3 rejected windows) [4], and whether the hybrid beats every single-domain space and FBCCA argmax is the lowest supervised reference [1, 4]. It also produces the S01–S05 flagship values that P06 reproduces as R-5 (cohort, leaky, 83.33 % / 87.57 %) [1, 4].

### 4.3 Feature space × model table (S03, 1.0 s / 2.0 s smoothed, %)

```python
import pandas as pd
b = pd.read_csv("reports/feature_space_benchmark_S03.csv")
ARG = "FBCCA argmax (zero-training)"
a1, a2 = "1.0s Acc (%)", "2.0s Smoothed (%)"
sup = b[b["Model"] != "argmax"]
spaces = [s for s in dict.fromkeys(b["Feature space"]) if s != ARG]
print("| Model | " + " | ".join(f"{s} (p={sup.loc[sup['Feature space'] == s, 'p'].iloc[0]})" for s in spaces) + " |")
print("|---|" + "---|" * len(spaces))
for m in dict.fromkeys(sup["Model"]):
    cells = []
    for s in spaces:
        r = sup[(sup["Feature space"] == s) & (sup["Model"] == m)]
        cells.append(f"{r[a1].iloc[0]:.2f} / {r[a2].iloc[0]:.2f}" if len(r) else "not in benchmark")
    print(f"| {m} | " + " | ".join(cells) + " |")
best = sup.groupby("Feature space", sort=False)[[a1, a2]].max()
print("| Best of 9 (1.0 s / 2.0 s) | " + " | ".join(f"{best.loc[s, a1]:.2f} / {best.loc[s, a2]:.2f}" for s in spaces) + " |")
am = b[b["Model"] == "argmax"].iloc[0]
print(f"FBCCA argmax (zero-training, p=5): {am[a1]:.2f} / {am[a2]:.2f}")
hy = sup[sup["Feature space"].isin(["FBCSP + FBCCA (in-fold)", "Harmonic PSD + FBCCA"])]
print("hybrid supervised rows", len(hy), "| min 1.0 s", hy[a1].min(), "| argmax below all", bool(am[a1] < hy[a1].min()),
```
