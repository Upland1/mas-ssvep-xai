## 1. What this phase tests

Roadmap P19 [1]: filtering can hide artifacts, so the limits are also checked on unfiltered windows cut at the same positions. Tasks: `subject_quality_gate(..., raw_windows, raw)` with `params["source"]` in `{filtered, raw, both}`; a channel or window must pass on every checked signal; windows failing only on raw get reason 3; `build_windows.py --quality-source`; config default `both`; `rejected_by_label` reports reasons 1/2/3 [1]. Numbered P19.1–P19.4 [1]. Acceptance, verbatim [1]: "Acceptance: per-subject rejection breakdown by reason for filtered/raw/both; flagship re-run on `both` vs `filtered` (record the difference)."

Questions:
1. Does a raw check reject windows that the filtered check accepts, per subject, per reason and per label?
2. Does the flagship 5-class accuracy change when the source is `both` instead of `filtered` (1.0 s and 2.0 s smoothed, base and harm bank)?
3. Does `source=filtered` reproduce the P16 and P17 decision exactly (settled point 3 [2])?

Pre-committed before the run [2, 7, 8]: settled points 1–9 (decisions row 147 [8]); checks A–F (run-list additions, copied into `02_plan.md` [2]); the expected outcome, a null or near-null with the raw gate pinned to S03 row 160 only [7, 8]; the materiality rule of P17, |Δ| ≥ max(2σ, 2 windows) [2]. The pre-run audit passed with notes C-1 to C-4 [7, 8]. The null wording was amended after the results review (D-3, decisions row 149 [8]); §4.4 uses the amended wording.

## 3. How to run

Commands as in `02_plan.md` [2] and run in `05_run.md` [5]. The verifier ran from a clean worktree with symlinks to the main tree's data, reports and `.venv` [5].

```bash
P=".venv/bin/python -m"
BUILD="$P scripts.build_windows --filter-mode continuous --subjects S01 S02 S03 S04 S05 --session OO --banks fbcca fbcsp harmonic intermediate"
$BUILD --quality-source filtered --out-root mas/state/scratch/p19_filtered
$BUILD --quality-source raw      --out-root data/processed_continuous_p19_raw
$BUILD --quality-source both     --out-root data/processed_continuous_p19_both
B="$P scripts.benchmarks.feature_based.benchmark_n_subjects --quality shared --cv-repeats 10 --classes 5"
$B --data-root data/processed_continuous_p17      --bank base --out-suffix p19_filtered_base
$B --data-root data/processed_continuous_p19_both --bank base --out-suffix p19_both_base
$B --data-root data/processed_continuous_p17      --bank harm --out-suffix p19_filtered_harm
$B --data-root data/processed_continuous_p19_both --bank harm --out-suffix p19_both_harm
```
