## 1. What this phase reproduces

Origin, verbatim from the roadmap as quoted in `00_assignment.md`: "Professor (Oct 11): treat it as a detection problem, test different window sizes, identify which frequency it is, and run online with a neural network" [1]. The original project has no preserved number for this step (R-16) [1, 2]. The phase asks four questions:

1. How do accuracy and window-level ITR depend on window length (0.5–4 s, stride 0.25 s) for FBCCA, in-fold FBCSP+FBCCA LDA and a CNN (`compact_eegnet`)? [1, 2]
2. Which 1 s network (`ccnn`, `compact_eegnet`, `eegnet`) performs best under grouped early stopping? [1, 2]
3. How does dynamic stopping on the window probabilities trade decision time against accuracy? [1, 2]
4. Does a causal detector trained on OO and replayed on mOO detect the targets, and what does a sixth (rest) class change, at 5 and 6 classes? [1, 2]

The pre-committed directions P1–P6 and reporting rules R-P1–R-P12 are in `02_plan.md` [2].

Commands as run by the verifier from a clean worktree, with the binding order 0, 1, 2a, 3, 4a, 5, 6, [S], 2b, 4b, 7 [2, 7, 8]. The timings are from `05_run.md` [10].

```bash
P=".venv/bin/python -m"
# 0. hash data/processed_continuous/S0* (before)

for W in 0.5 1 1.5 2 3 4; do $P scripts.build_windows --filter-mode continuous --subjects S01 S02 S03 S04 S05 --session OO --banks fbcca fbcsp --quality-source both --window-sec $W --stride-sec 0.25; done
# 2a. window sweep, classical part (fbcca, lda)
$P scripts.benchmarks.benchmark_window_sweep --data-root data/processed_continuous --windows 0.5 1 1.5 2 3 4 --stride 0.25 --methods fbcca lda --cv-repeats 5 --out-dir reports/window_sweep
# 3. NN sweep at 1 s
$P scripts.benchmarks.neural_networks.benchmark_nn_sweep --data-root data/processed_continuous --windows 1 --models ccnn compact eegnet --out-dir reports/nn_sweep
# 4a. dynamic stopping, lda only (binding item C)
$P scripts.benchmarks.simulate_dynamic_stopping reports/window_sweep/predictions.csv --thresholds 0.5 0.6 0.7 0.8 0.9 0.95 --skip-sec 0.5 --out-dir reports/dynamic_stopping_lda
# 5-6. pseudo-online, 5 and 6 classes, quality source named (binding item A)
$P scripts.benchmarks.pseudo_online --train-session OO --test-session mOO --model ccnn --window-sec 0.5 --stride-sec 0.25 --skip-sec 0.5 --threshold 0.6 --quality-source both --tag ccnn_5class
$P scripts.benchmarks.pseudo_online --train-session OO --test-session mOO --model ccnn --window-sec 0.5 --stride-sec 0.25 --skip-sec 0.5 --threshold 0.6 --rest-class --quality-source both --tag ccnn_6class
```

### 4.2 Window sweep (acceptance 1; R-P1, R-P2, R-P3)
