## 1. What this phase tests

Roadmap P15 origin: "Professor's assignment: model connectivity with graph neural networks to classify the stimulation frequency. Plan: first test whether connectivity features add information to power features (a 'gate'), then a GNN" [1]. Two questions:
- **The gate (R-14).** Do edge features (coherence, phase) add information to node power and FBCCA features under a Shrinkage-LDA pipeline?
- **The GNN (R-15).** Does a within-subject graph neural network reach the reference per-subject accuracies, do nodes+F and nodes+coh+F agree, and do coherence edges help?

Acceptance, verbatim from the roadmap [1]: "gate table = **R-14** (Base+Ec best mean 77.6 %, gate does **not** pass); GNN = **R-15** (nodes+F ≈ nodes+coh+F; coherence edges do not help); smoke test passes."

The acceptance windows A1–A8 were fixed in the pre-run audit, before any real-data run; the results review did not move them [7]. Settled points (decisions.md P15 row 127): CV, metrics, verdict rule, the GNN variants, the multi-seed rule, the cache, and test hygiene [5].
