# Trial-Grouped, Continuously Filtered Evaluation of a Five-Class SSVEP Decoder: Leakage Correction, Connectivity Statistics, Detection and Leave-One-Subject-Out

*Technical report v2 of the mas-ssvep-eeg-xai rebuild (phase P24). It supersedes the historical report v1 (`docs/report/v1/report.md`, P06), whose "leakage-free" claim was wrong. Every number is copied from a CSV or log under `reports/` (git-ignored, regenerated by `make all`) or from a phase record that quotes one; the path is given with the number. Reference values of the original project are labelled R-x and are targets for diagnosis, not results of this work.*

## Abstract

We rebuilt a five-class steady-state visually evoked potential (SSVEP) decoder for eight parieto-occipital channels recorded at 256 Hz and reproduced the original project's history in gated phases. The legacy protocol used window-level cross-validation, which places windows of one trial in both training and test folds. With trial-grouped cross-validation the classical flagship (FBCSP and FBCCA features, scaler, Shrinkage-LDA) falls from 83.33 % to 79.28 % at 1.0 s on five subjects (S01–S05), a classical inflation of 4.06 percentage points (pp) (`reports/cv_leakage_demo.csv`). The corrected continuous build (recorded 256 Hz, continuous filtering before windowing, eight-channel montage, true trial identifiers, one shared quality gate) gives 87.38 % at 1.0 s (`reports/v1_vs_v2/flagship.csv`); a narrow harmonic filter bank raises the five-class result to 94.29 % (`reports/n_subjects_benchmark_p17_harm_5class.csv`). Leave-one-subject-out (LOSO) Shrinkage-LDA reaches 87.61 % and a within-subject reference 90.79 % on the same channels (`reports/loso_w1_p22_common/summary.csv`). The P23 connectivity-edge graph neural network (GNN), a three-seed ensemble, gives 89.22 % under LOSO and 86.81 % within subject (`reports/loso_gnn/summary.csv`, `reports/within_gnn/summary.csv`). Several results do not replicate the original project's numbers: the sequential forward selection row (§2.3), one Compact-CNN cell (S03, 2.0 s, augmentation ON) and one legacy GNN cell (S02, 2.0 s). We report them as documented deviations. The cohort is five subjects; the findings are descriptive for that cohort and do not establish performance on new participants.

## 1. Introduction

SSVEP brain–computer interfaces decode the frequency of a flickering target from scalp EEG. The paradigm has five targets at 24.00, 20.00, 15.00, 10.9091 and 8.5714 Hz, shown in 5-second segments with a fixation cross (code 201) and a cue (code 202) around each trial [1, 2]. The original project of this rebuild built a classical pipeline and a series of neural and graph models on these recordings. Its published numbers include a leak-free flagship, an augmentation A/B for three networks, a connectivity gate, a connectivity statistics study and a leave-one-subject-out study [3]. The rebuild replays that history in 26 phases, reproducing legacy behaviour where the roadmap requires it and fixing each defect with a before/after comparison [4].

This report has three aims. First, to correct the evaluation: to measure the size of the trial leak and to report corrected numbers. Second, to document the Era-C changes (sampling rate, continuous filtering, valid windows, a sixth rest class, harmonic and intermediate bands, graph-level connectivity statistics, window length and detection, LOSO and a GNN under LOSO). Third, to report every deviation from the original numbers rather than tuning toward them [4].

## 2. Materials and Methods

### 2.1 Data source

The recordings are the `OO` (on-off flicker) calibration session of five participants, S01–S05, and the `mOO` run used as a pseudo-online test set. Of the 23 recordings in the measured inventory, 10 were delivered (OO and mOO of S01–S05); the 13 others are absent and no phase uses them [2, 5]. Each run has 40 trials of 8 per target in randomized order, and the recordings are sampled at 256 Hz [2, 6]. Channels are `PO7, PO3, POz, PO4, PO8, O1, Oz, O2`; PO7 is excluded in the legacy configuration and restored in P07 [6, 7]. The P21 LOSO study also ran on a 39-subject cohort (S01–S040 without S020) as a separate data source; this report uses the 5-subject cohort for every main result [14].

### 2.2 Legacy and corrected protocols

Legacy behaviour is reproduced and labelled. Its defects are the window-level cross-validation (PF-01), the `i % 5` smoothing that is misaligned after a rejected window (PF-02), the assumed 250 Hz sampling rate (PF-04), per-window sub-band filtering (PF-14) and a per-script quality gate (R5, legacy by design) [4, 8]. The corrected protocol (from P16) uses trial-grouped cross-validation, `StratifiedGroupKFold(5, shuffle, 42)` on trial identifiers (R1), continuous filtering before cutting (R3), fs from the recording metadata and one shared quality decision with explicit thresholds (R5) [4].

Trial identifiers on legacy folders are reconstructed from pre-gate labels and indexed with the gate's mask (PF-03). Approximate identifiers remain on S02 and S04 (39 of 199 and 38 of 198 stimulus windows are in inconsistent legacy groups); the corrected continuous build has true identifiers [5, 7].

### 2.3 Features and classifiers

FBCSP uses five sub-bands, (7, 12), (13, 17), (18, 26), (27, 36) and (38, 52) Hz, with one one-vs-rest CSP component per side (m = 1), fitted on the training rows of each fold [5]. FBCCA gives five canonical-correlation scores with three harmonics. The flagship classifier is a `StandardScaler` followed by Shrinkage-LDA [5, 9]. Feature selection (ANOVA, mutual information, sequential forward selection and sub-band pruning) is in-fold [5]. Our sequential forward selection row (scikit-learn `SequentialFeatureSelector`, forward, Pipeline(StandardScaler, Shrinkage-LDA lsqr auto), inner unshuffled stratified `cv=5`, accuracy scoring, 15 of the 50 FBCSP columns plus the 5 FBCCA scores, fitted in-fold; 20 features) is a reconstruction from the R-4 record (84.77 / 93.40 %; `mas/04_REFERENCE_RESULTS.md`). The original repository has no sequential forward selection code, so the configuration behind R-4 is unknown and remains an open question (D-1; `mas/state/reports/P06.md` §9, items b and c) [30, 33]. The continuous-build banks of P17 are `base` (the five FBCSP sub-bands), `harm` (base plus k·f bands, k = 1..3) and `harm+mid` (plus midpoints), each ±1 Hz and order 2 [7, 8].

### 2.4 Networks, augmentation and the training convention

Four legacy networks and three networks of the detection and LOSO phases are used. EEGNet (2,349 parameters at 7 × 256), Compact-CNN (`compact_cnn`, 56,021) and ShallowConvNet (`shallow_convnet`, 14,485) are three of the four legacy networks [6]. The fourth legacy network is `DualBranchFusionCNN` (P04; `src/models/cnn/spatial_spectral_cnn.py`) with 10,005 parameters (`reports/logs/P04/param_count_20261024T223559.log`). It fuses a spatial-spectral branch on a 4 × 8 map (four occipital channels by eight harmonic-PSD bins) with a branch on the five FBCCA scores, concatenated to 48 features before the head, and uses its own legacy convention (140 epochs, batch 16, label smoothing 0.1) [29]. P04 reports a mean of 78.75 % at 1.0 s and 83.76 % smoothed over S01–S05, under the leaky window-level `StratifiedKFold` and the no-reset smoothing (legacy). Per subject, 1.0 s / smoothed: S01 51.50 / 63.00; S02 53.77 / 64.32; S03 89.00 / 95.00; S04 99.49 / 97.98; S05 100.00 / 98.50 (`outputs/reports/batch_run_subjects.csv`, columns `CNN 1.0 s` and `CNN smoothed`; means quoted in `mas/state/reports/P04.md` §4.4; `.venv/bin/python -I -c "print(round(sum([51.5,53.77,89,99.49,100])/5,2), round(sum([63,64.32,95,97.98,98.5])/5,2))"` gives 78.75 and 83.76) [29]. The exported `outputs/models/S0x_fusion_cnn.pt` files are full-data fits for visualization and export only (R2 exception, `mas/state/reports/P04.md` §4.5); their training-window accuracies (93.50 % for S01, 100.00 % for S04) are not test scores [29]. `compact_eegnet` and `eegnet` (kernel 128) and `ccnn` are the P20–P21 networks [10, 12]. `ccnn` has 27,977 parameters at 7 channels and 32,309 at 8 (`reports/nn_sweep/summary.csv`, column `Params`) after the P25 layout fix. The naming is kept distinct (PF-31): `compact_cnn` is the `CompactCNN` class and is not `compact_eegnet`. Training uses per-window z-scoring, AdamW (weight decay 1e-2), cosine annealing, label smoothing 0.05 and seed 42 + fold. In the P20–P23 protocol the validation split is 20 % of training trials, patience 25 and at most 150 epochs. Augmentation (Gaussian noise, amplitude scaling, time shift and intra-class mixup, each with probability 0.5) is applied to the training fold only [6]. Training accuracy is measured on the un-augmented training fold (PF-30).

**CCNN spec deviation, fixed in P25 (fix round 1, code in 987742b).** From P20 to P24 the CCNN stacked [real, imag] as two input maps with bias-free convolutions (pre-P25 layout, non-conforming: 14,817 / 17,285 parameters). The roadmap and R-8 require one `[real | imag] / T` map with convolution biases (27,977 / 32,309 parameters). Every CCNN value produced before P25 is non-conforming and superseded; the CCNN values in this document are the P25 regenerated outputs.

### 2.5 Connectivity and graph statistics

Coherence is estimated once per condition from concatenated windows (R4), not averaged per window, because the per-window average is biased upward (PF-15). The baseline is the matched 201 windows in the stimulus band (PF-16). Phase connectivity uses the cross-spectral density (R3); PDC uses a strided MVAR fit (PF-17, R6) [4, 9]. Statistics are trial-level permutations with the observed group sizes (R7), Benjamini–Hochberg over edges (FDR) and the Network-Based Statistic (NBS), reported as separate criteria [9, 11]. Graph models use electrode nodes with power and FBCCA features and optional coherence edges [10].

### 2.6 Detection and LOSO

Window length is swept from 0.5 to 4 s (stride 0.25 s) for FBCCA, in-fold LDA and a network, with accuracy and window-level information transfer rate (ITR, bits/min with N = 5) [12]. A pseudo-online detector is trained on OO and replayed causally on mOO [12]. LOSO trains on every subject but one (the group is the subject, R1); the within-subject reference uses `StratifiedGroupKFold(5)` on trial identifiers of the same subject [11]. Three networks were run under the same LOSO protocol with in-fold normalization: `ccnn` and `eegnet` at seeds 42, 43 and 44, and `compact_eegnet` at seed 42 only (§3.6) [27]. The LOSO lda_subjnorm rows normalize each held-out session with its own unlabelled whole-session statistics. These are test-time normalization results and an offline upper bound: the held-out session's unlabelled statistics are used, and no labels are used (R2 exception). A first-K warm-up study (K trials, unlabelled) is reported separately [11, 14].

### 2.7 Reproducibility

Each phase ran its commands from a clean checkout, and the verifier reproduced the reported CSVs. The full test suite runs on CPU without recordings (1513 tests passed at P23) [14]. All CSVs are regenerated by `make all`; the per-phase targets are listed in the README. Relative to the original repository, this rebuild adds seven capabilities with no counterpart there: the raw-inventory script, the P05 five-subject benchmark (a frozen legacy snapshot), the parameter-count script, the connectivity bug demonstrations, the CV-leakage, v1/v2-comparison and network-seed-spread diagnostics, the one-command `Makefile`, and the synthetic test suite (81 `test_*.py` files) [26].

### 2.8 Explainability (legacy, full-data fit)

The explainability figures of P04 use the Shrinkage-LDA of the legacy hybrid: `StandardScaler` followed by Shrinkage-LDA (lsqr, automatic shrinkage) on 37 legacy features, 32 harmonic-PSD values on POz, O1, Oz and O2 at eight bins (9, 11, 15, 17, 20, 22, 24 and 30 Hz) and five FBCCA scores, at the assumed fs 250 (PF-04) [15, 16]. The model is fitted on all windows of one subject (S04 by default, S01 for the two-subject comparison), and the coefficients are reshaped into 5 × 4 × 8 spatial-spectral and 5 × 5 FBCCA matrices. The coefficients are weights on z-scored features, so magnitudes are comparable across features [15]. This is a full-data fit for visualization and export only: the R2 exception of the era matrix (legacy Era A) [4]. It is **not an accuracy estimate**; the weights describe the fit, not generalization to new trials or subjects.

#### 3.1.1 Raw-signal quality option (P19)

The continuous build takes one quality decision per subject (R5). Its signal is set by `--quality-source` of `scripts/build_windows.py` (and of the pseudo-online script), with the values `filtered`, `raw` or `both` listed in `SOURCES` of `src/preprocessing/window_quality.py` [22]. `filtered` applies the Vpp/std gate and the artifact guard to the filtered windows (reasons 1 and 2). `raw` checks the unfiltered window cut at the same starts (reason 3 only). `both` takes the filtered decision and then adds the raw check (reason 3). The config default is `both` (`configs/pipeline_config.yaml`, line 39) [22]. Over the five OO recordings (320 windows per subject, 1,600 in all) the rejected count is 43 under `filtered`, 44 under `both` and 44 under `raw` (`mas/state/reports/P19.md` §4.2, from `reports/logs/P19/12_tables.txt`) [22]. `raw` is a different check, not a stricter one [22].

On the five-class benchmark (base and harmonic banks, ten repeats, stimulus windows) `both` against `filtered` changes no cell materially. The only change is S03 base: 93.76 to 93.52 % at 1.0 s (−0.24 pp, materiality threshold 2.40 pp) and 93.92 to 93.83 % at 2.0 s (−0.09 pp, threshold 2.32 pp) (`reports/n_subjects_benchmark_p19_filtered_base.csv`, `reports/n_subjects_benchmark_p19_both_base.csv`). The per-subject change is therefore the only accuracy change in the base bank; the base Mean row moves from 87.65 to 87.6 at 1.0 s and from 89.57 to 89.55 at 2.0 s, and the harmonic S03 standard deviations move from 0.22 to 0.33 at 1.0 s and from 0.0 to 0.24 at 2.0 s (`reports/n_subjects_benchmark_p19_filtered_harm.csv`, `reports/n_subjects_benchmark_p19_both_harm.csv`) [22]. P19 reads this as split variation from a changed partition, not as an effect of the raw check; the one window that `both` adds is a threshold-boundary crossing on PO4 (119.4 µV filtered, 121.9 µV raw, limit 120 µV) [22]. No benchmark was run on `raw` alone, and no CSV holds a `raw`-only accuracy [22].

#### 3.4.1 Power and alpha confounds (P14.3, P18)

Does the connectivity delta follow target SSVEP power and alpha change? P14 regresses the delta of each method on target SNR (dB, O1, Oz and O2, f0 ± 1 Hz) and on alpha change (dB, 8–13 Hz outside f0 ± 1.5 Hz) over 25 cells (five subjects by five frequencies). The data are the legacy 7-channel OO windows (Era B) [20]. For coherence the joint R² is 0.6750, with SNR alone 0.6681 and alpha alone 0.0179; alpha adds 0.0069, so the SNR share is 0.990 (`reports/connectivity_comparison/power_confound_ols.csv`) [20]. Within subjects (centred), the joint R² is 0.5400, with SNR alone 0.5251 and alpha adding 0.0149. The pooled value includes between-subject differences, so the centred value is the within-subject statement. PLV and PDC are partly explained (R² 0.4293 and 0.4346, SNR-dominated); wPLI is explained between subjects only (centred R² 0.0014) [20]. The coherence delta rises with target SNR (Spearman ρ 0.707) and not with alpha change (ρ −0.124) (`reports/connectivity_comparison/power_confound_correlations.csv`). The in-alpha cells (10.91 and 8.57 Hz) have lower SNR (2.02 dB against 4.81 dB) and lower coherence deltas (0.0128 against 0.0467) (`reports/connectivity_comparison/power_confound_alpha_split.csv`). The reading is SNR-dominated. Alpha change is negative in 23 of 25 cells (`reports/connectivity_comparison/power_confound_table.csv`) and adds little.

P18 did not revisit this regression. It re-ran the alpha-band p-values on the continuous build with 1000 permutations (`reports/connectivity_alpha_diagnostic_p18_nbs.csv`) [21]. That file is the final alpha diagnostic for Era C; the 200-permutation P18 file (`reports/connectivity_alpha_diagnostic_p18_nbs_p200.csv`) is used only for the R7 check, and the P13 table (`reports/connectivity_alpha_diagnostic.csv`, legacy build) and the `diagA2_rs*`, `window200`, `trial100`, `v1*`, `v2*` and `aligned_S03` variants are diagnostics that are not used for the reading. In the final file the S05 coherence decrease at 10.91 Hz (delta −0.0801, lower-tailed p 0.0070) is stable at 200 permutations (0.0050). At 8.57 Hz (delta −0.0698) the lower-tailed p is 0.04995 at 1000 permutations and 0.05970 at 200, a flip across 0.05, so the cell is inconclusive under R7 [4]. Of the 24 lower-tailed tests of S03 to S05 at 1000 permutations (three subjects, four methods, two frequencies), four are below 0.05 uncorrected, all in S05 (one of them, coherence at 8.57 Hz, is inconclusive under R7): coherence at 10.91 and 8.57 Hz and PLV at 10.91 and 8.57 Hz (`reports/connectivity_alpha_diagnostic_p18_nbs.csv`, rows S03–S05 with condition 104 or 105).

### 3.5 Connectivity gate and graph neural network (within subject)

The connectivity gate asks whether edge information adds to node power and FBCCA features. ## 4. Discussion

**The leak and its size.** Window-level cross-validation inflates the classical flagship by 4.06 pp at 1.0 s and 4.96 pp at 2.0 s on five subjects. The inflation is reproduced on every subject and is largest on S02 (−10.21 pp), where approximate trial identifiers survive [5]. The network inflation in the original is not reproduced here. Like for like, the three-base EEGNet cohort drop is −2.71 pp (OFF) and −2.82 pp (ON), against the seed-42 cohort drop of −5.57 pp; on S03 the seed-42 drop of −20.81 pp is of the same order as the three-base training-seed range of 16.75 pp (`mas/state/reports/P11.md`). 13 of 14 out-of-band augmentation cells are explained by seed variance; the one that is not (Compact-CNN S03 2.0 s ON: 129, 127 and 129 of 197 windows over three seeds, against a smallest in-band count of 131) is a documented deviation [5, 6, 14]. The leaky numbers are therefore not a basis for claims about networks.

**Augmentation.** Leak-free augmentation helps all three networks on average, most for Compact-CNN (+13.56 pp at 1.0 s, against the original's +17.16 pp). The gain is not a ranking of networks: the cohort means are on five subjects, and the legacy networks have one seed set in the A/B (Table 8; the per-subject seed ranges are in the P11 record) [6].

**Continuous filtering and sampling rate.** The largest corrected change is the sampling rate, not the filter. Continuous filtering improves the signal path (no window-edge effects) but does not change accuracy here, which is the expected result for a filter that acts on signal validity rather than on class information. The narrow harmonic bank carries the gain of the five-class result: its improvement is consistent with an SNR gain in the ±1 Hz bands at the harmonic frequencies, but the bank contains the fundamentals and the ablation (fundamentals only) is still open.

**Connectivity.** Connectivity statistics agree with the original's pattern at 24 Hz (significant in S03 to S05 for coherence and wPLI; S01 and S02 null) and differ in exact counts. The S05 wPLI total and the NBS and FDR cells that flip between permutation counts are inconclusive at five subjects, and the alpha-band prediction holds for coherence and PLV only [9, 13]. Graph sizes are large for S03 and S04 and small for S01 and S02, which suggests that graph-level statistics follow subject-level SNR rather than a frequency effect; this is a hypothesis on five subjects.

**Confusions.** Table 4 shows that most stimulus errors of the six-class model go to the rest class, which is consistent with the rest class absorbing weak responses. The low-frequency pair (10.91 and 8.57 Hz) is the most confused among the stimulus classes, as R-3 reports for the legacy model.

**Generalization.** Test accuracy is far below train accuracy on S01 and S02 for the legacy networks and for the LOSO GNN (gaps of 13.8 to 27.8 pp). For EEGNet with augmentation off, the legacy leaky values are 28.00 and 27.04 % test against 83.25 and 81.38 % train (`reports/legacy_leaky/augmentation_ab_eegnet.csv`, P10); the grouped values are 30.50 and 26.02 % test against 82.99 and 79.60 % train (`reports/augmentation_ab_eegnet.csv`, Table 8). This is a generalization failure, not an optimization failure. On S03 to S05 the LOSO test accuracy is above train accuracy by 1.4 to 5.6 pp. For lda the LOSO cohort mean is below the matched within-subject reference (§3.6); for the GNN the reference direction is not observed [11, 13].

**Limitations.** The cohort has five subjects (39 for LOSO only in the classical study), one OO session per subject for the main results, and one or three training seeds for the networks. Several differences are a few windows; one window is 0.51 pp at 197 windows. The sequential forward selection row (ours 89.85 / 95.94, R-4 84.77 / 93.40) is ours, not a reproduction (definition in §2.3). Within-subject GNN training reached the 150-epoch cap in 19 of 50 folds, a stated limitation. The trial-level permutation statistics are reported with their resolution limits [5, 9, 10].

**Pseudo-online session pairs.** Only one train/test pair was run: the detector is trained on OO and replayed causally on mOO (`mas/state/reports/P20.md`, data-source block at the top, line 17) [12]. Only OO and mOO of S01–S05 were delivered, 10 of the 23 recordings of the specification (`mas/state/blockers/B005-inventory-10-of-23-files.md`) [24]. The original's other sessions (`C`, `mC`, `online_C`, `online_OO`, `cb_mas_mcb`) are absent, so other session pairs could not be evaluated [24]. The reverse pair (mOO to OO) was not run, by decision of Sebastian on 2026-10-30 [25]. The pseudo-online values of §3.7 are therefore one pair, at seed 42 only. The script itself takes `--train-session` and `--test-session` (`scripts/benchmarks/pseudo_online.py`, defaults OO and mOO), so the method accepts any pair and the limitation is the delivered data [32].

## 5. Conclusion

Trial-grouped cross-validation corrects the legacy leak: the classical flagship is 79.28 % at 1.0 s and 82.61 % at 2.0 s on five subjects, against 83.33 % and 87.57 % for the leaky protocol (`reports/n_subjects_benchmark.csv`). The corrected continuous build reaches 87.38 % (`reports/v1_vs_v2/flagship.csv`), and a narrow harmonic bank 94.29 % (`reports/n_subjects_benchmark_p17_harm_5class.csv`). Under LOSO, Shrinkage-LDA reaches 87.61 % and the within-subject reference 90.79 % on the common channels; the connectivity-edge GNN, as a three-seed ensemble, reaches 89.22 % under LOSO and 86.81 % within subject. Each result is for five subjects, and the deviations of §3 and §4 are reported rather than removed. The next steps are the open items of the progress report: the sequential forward selection configuration (§2.3), the smoothing rule on legacy folders, the cause of the single unreproduced cells, and a second cohort. Two directions remain open. First, normalizing the held-out subject under LOSO with statistics from its own fixation-cross (condition 201) windows, instead of its first K stimulus trials (`scripts/benchmarks/benchmark_loso_warmup.py`), so that a new user would only look at the cross before use; the classification stays five-class. The original project planned this run on 2026-10-20 ("test LOSO normalization using the rest (cross) windows instead of the first trials"), but its results file was never filled in [34]; this rebuild does not implement it either (the LOSO scripts use `CLASS_CODES = (101, 102, 103, 104, 105)`, `src/io/subject_data.py` line 37, and no code reads 201 windows for normalization) [31]. Second, Granger-causality and mutual-information connectivity are not implemented in this rebuild (grep of `src/` and `scripts/`: no Granger code; mutual information only as a feature-selection criterion) [31]; the original repository leaves them open as well, as recorded by the independent review's R11 read (`mas/state/scratch/reference_access.log`, entries of 2026-10-30, lines 60–65): its README lists Granger-causality and mutual-information connectivity as not yet implemented, with both entries commented out as queued in `analyze_connectivity.py` (branches main, feature/window-size-online-detection and test/GNN-testing-LOSO) [33].
