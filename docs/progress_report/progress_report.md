# Progress report: SSVEP decoding rebuild, assignments and open questions

*Consolidated report for the professor, phase P24. One section per assignment in the roadmap (task 5), each with the question, what was done (phase), the result table with its data source, and the open questions. Every number is copied from a CSV under `reports/` (git-ignored, regenerated by `make all`) or from a phase record that quotes one; the path is given with the number. Reference values of the original project are labelled R-x and are targets for diagnosis, not results of this work. The cohort is S01–S05 unless a table says otherwise.*

## 0. Summary

The rebuild reproduces the original project's legacy pipeline and corrects it in gated phases (P00–P23). The corrected classical flagship reaches 79.28 % at 1.0 s on five subjects under trial-grouped cross-validation, down from 83.33 % under the legacy window-level protocol (`reports/n_subjects_benchmark.csv`, `reports/cv_leakage_demo.csv`). The corrected continuous build reaches 87.38 % (`reports/v1_vs_v2/flagship.csv`). The results below answer the ten assignments of the roadmap, plus the connectivity-gate and within-subject GNN work of P12–P15. Five subjects are the only cohort for the main results.

## 1. Edge effects of per-window sub-band filtering (P16)

**Question.** Does filtering each 1 s window separately distort the window edges, and how much?

**What was done.** Edge error and centre error of the sub-band filters were measured on S03 (P16, `scripts/diagnostics/demo_edge_effects.py`).

**Result** (`reports/edge_effects_summary.csv`, S03, edge-to-centre ratio, edge error %, centre error %):

| Band (Hz) | Ratio | Edge error (%) | Centre error (%) |
|---|---|---|---|
| 7–12 | 8.17 | 53.24 | 6.51 |
| 13–17 | 7.45 | 56.68 | 7.60 |
| 18–26 | 21.00 | 33.10 | 1.58 |

The pre-committed criterion (ratio at least 5 and edge error at least 20 %) is met. The order-of-magnitude reading (ratio at least 10) is not met for the two lowest bands, and the report says so.

**Open questions.** None on the measurement; the edge effect is the reason for continuous filtering (section 2).

## 2. Continuous filtering before windowing (P16)

**Question.** Does filtering the continuous recording before cutting windows change accuracy, and what else changes with it?

**What was done.** A continuous build of the windows (filter first, then cut; fs from the header, 256 Hz) was compared with the legacy path in five steps, each one changed alone: sampling rate, build, filter mode, smoothing rule and guard (`reports/v1_vs_v2/flagship.csv`, five seeds 42–46).

**Result** (cohort mean, 1.0 s / 2.0 s, %):

| Version | 1.0 s | 2.0 s |
|---|---|---|
| v1 frozen (legacy, R-6 reference) | 79.28 | 82.61 |
| a: legacy, fs 250, five seeds | 80.80 | 84.42 |
| a′: fs 256 | 88.84 | 91.33 |
| b: per-window build | 87.01 | 89.12 |
| c: continuous build with guard (v2 headline) | 87.38 | 89.07 |
| c′: continuous build, no guard | 88.38 | 89.83 |

The sampling-rate correction is the material step (a′ − a = +8.04 / +6.91 pp, positive in every subject). The filter mode changes accuracy by +0.37 pp (not material). Continuous filtering is the correct signal path (R3) with no accuracy effect here.

**Open questions.** The guard (c − c′ = −1.00 pp; material only on S02 at 1.0 s, −4.50 pp) has no established cause. The S02 build factor (−8.03 pp) mixes restored PO7, the removal of approximate trial ids and six fewer windows; a diagnostic was optional and is not run.

## 3. Valid windows: quality gate and trial identifiers (P07, P11, P16, P19)

**Question.** Which windows are valid, and do the trial identifiers of the windows agree with the trial structure?

**What was done.** A two-tier gate was added (P07): tier 1 drops a channel for the subject when it fails the limits in more than 50 % of windows; tier 2 rejects windows on the surviving channels (vpp 5–120 µV, std 1–35 µV). P16 made the gate shared by all features (R5). P19 checks the raw, unfiltered signal too (`quality.source = both`). Trial identifiers were reconstructed on legacy folders from pre-gate labels (P11).

**Result.** Clean and rejected windows of the corrected continuous build (`reports/n_subjects_benchmark_v2cont.csv`): S01 200 / 0, S02 190 / 10, S03 194 / 6, S04 195 / 5, S05 199 / 1. Raw-signal check (P19, `reports/n_subjects_benchmark_p19_*`): rejected windows of 1600 are 43 (filtered), 44 (both) and 44 (raw); the flagship changes are not material. The legacy folders keep approximate trial identifiers on S02 and S04 (39 of 199 and 38 of 198 stimulus windows; P16).

**Open questions.** The legacy PF-07 cause (PO7 `vpp_high`, not `vpp_min`) and whether the original's P07 changed both the montage and `vpp_min` together (decision of P07, D-1). The approximate identifiers on S02 and S04 of the legacy folders are a residual leak until the continuous build replaces them.

## 4. Sixth (rest) class and harmonic / intermediate bands (P17)

**Question.** Does adding the fixation cross as a sixth class and narrow harmonic and intermediate bands change the results?

**What was done.** Bands k·f (k = 1..3) and midpoints (±1 Hz, order 2) were added to the filter bank, with 5 and 6 classes, ten CV repeats and the rest class from code 201 only. The narrow bands ring to 1.047 s, so the guard of the new build is 1.047 s; the new build went to its own folder (`data/processed_continuous_p17/`) and the P16 folder was not changed.

**Result, five classes** (cohort mean, 1.0 s / 2.0 s, %; `reports/n_subjects_benchmark_p17_*_5class.csv`):

| Bank | 1.0 s | 2.0 s |
|---|---|---|
| base (five FBCSP sub-bands) | 87.65 | 89.57 |
| harm (base + harmonics) | 94.29 | 95.80 |
| harm + mid | 94.23 | 95.45 |

**Result, six classes, 2.0 s** (cohort mean, %; `reports/n_subjects_benchmark_p17_*_6class.csv`): StimCorrect / FalseAct / Missed: base 85.63 / 7.85 / 8.67; harm 88.39 / 2.10 / 10.15; harm + mid 88.52 / 2.05 / 9.93. StimCorrect(6) is below Smoothed(5) in 15 of 15 cells. The narrow banks mainly reduce false activations on S01 and S02 (22.00 → 7.12 % and 16.08 → 3.24 % at 2.0 s).

**Refuted a-priori directions.** "Missed > FalseAct" for base on S01 (FalseAct 22.00 is above Missed 14.25); "loss ≈ Missed" on S01 and S02.

**Open questions.** Is the harmonic gain an SNR gain of the ±1 Hz bands (the fundamentals are in the bank) or a harmonic effect? The fundamentals-only ablation (P17 C-d) has not been run, so no gain is attributed to harmonics alone. Per-offset Missed and FalseAct (P17 C-e) are not computed.

## 5. NBS versus edge-wise FDR and graph sizes (P18)

**Question.** Is the graph-level Network-Based Statistic (NBS) more or less sensitive than edge-wise FDR, and how large are the significant graphs across subjects and frequencies?

**What was done.** Trial-level permutations (1000) on the continuous build, with FDR and NBS kept as separate criteria (R7); graph sizes as a share of possible edges.

**Result** (100 cells = 5 subjects × 4 methods × 5 frequencies; `reports/connectivity_cohort_summary_p18_nbs.csv`): cells positive by A-FDR 48, by A-NBS 43 and by B (global p) 32. Nine cells are FDR-only and four NBS-only: neither criterion is uniformly more sensitive. Largest-component share of possible edges (`reports/connectivity_graph_size_p18_nbs.csv`): S03 38.8 %, S04 32.1 %, S05 12.1 %, S01 2.6 %, S02 1.6 %. Mean over subjects and methods: 26.4 % at 24 Hz, 19.1 % at 20 Hz, 13.0 % at 15 Hz, 13.9 % at 10.91 Hz, 14.8 % at 8.57 Hz.

**Open questions.** Seventeen cells flip between 200 and 1000 permutations and are inconclusive (R7). The pairwise frequency tests are exploratory: 26 of 28 NBS-positive cells involve 10.91 or 8.57 Hz. Lower-tailed NBS for alpha frequencies (C-4) is an option, not run.

## 6. Detection and the window sweep (P20)

**Question.** How do accuracy and information transfer rate (ITR) change with window length, and which window is most informative per minute?

**What was done.** Window lengths from 0.5 to 4 s (stride 0.25 s) on the continuous build, OO session, for FBCCA, in-fold LDA and a network (`compact_eegnet`; PF-31 name). ITR is window-level, bits per minute, with N = 5.

**Result** (cohort mean, accuracy % / ITR bits/min; `reports/window_sweep/summary.csv`):

| Window (s) | LDA | FBCCA | compact_eegnet |
|---|---|---|---|
| 0.5 | 81.80 / 84.37 | 69.16 / 57.50 | 80.75 / 87.25 |
| 1.0 | 89.89 / 70.03 | 81.72 / 56.56 | 92.08 / 74.53 |
| 2.0 | 95.63 / 48.82 | 92.11 / 44.60 | 95.51 / 48.43 |
| 4.0 | 98.03 / 28.93 | 96.86 / 28.15 | 83.10 / 21.56 |

The ITR is highest at 0.5 s for every method. The 4 s network value is driven by S02 (39.56 %), where two folds restored an early-stopping state from epoch 1–3 (single repeat; an early-stopping failure, not a finding about length). Dynamic stopping (thresholds chosen in-sample, descriptive) gives 61.53 bits/min for LDA at 0.5 s against 60.23 for the time-matched single window (`reports/dynamic_stopping/best_threshold.csv`; `mas/state/reports/P20.md`).

**Open questions.** Early-stopping failures on S02 (flagged folds; a single-repeat rule of three repeats before a cohort change is interpreted). The dynamic-stopping thresholds were selected in-sample.

## 7. Pseudo-online detection (P20)

**Question.** Does a causal detector trained on one run work when replayed on another run?

**What was done.** The detector (`ccnn`) was trained on OO and replayed as a causal stream on mOO, with a label-free channel check and a 1 s fallback (`scripts/benchmarks/pseudo_online.py`).

**Result** (`reports/pseudo_online/summary_ccnn_5class.csv`, `reports/pseudo_online/summary_ccnn_6class.csv`): five classes, accuracy 89.00 % and 27.5 % false activations; six classes (rest class), 74.00 % and 5.0 % false activations. The two runs have different class sets, so they are not a before/after pair. The six-class drop is missed stimulus periods in S01 (50.00 %) and S02 (52.50 %). The six-class ITR uses N = 5 (44.56 bits/min).

**Open questions.** The mOO run is a second recording of the same paradigm; the paradigm of the `m` prefix is not documented in the project and is treated as a second run.

## 8. Leave-one-subject-out (P21, P22)

**Question.** How well does a model generalize to a subject it has never seen, and how does that compare with a within-subject model on the same channels?

**What was done.** LOSO trains on every subject but one (the group is the subject). Methods: fbcca, lda, lda_subjnorm (test-time normalization from the held-out session's unlabelled statistics, an offline upper bound), and the networks. P22 adds `within_lda` on exactly the LOSO channels and a warm-up study (K unlabelled trials).

**Result, cohort S01–S05, 1.0 s, seven common channels** (cohort mean, %; `reports/loso_w1_s01-s05/summary.csv`, `reports/loso_w1_p22_common/summary.csv`):

| Method | Protocol | Mean |
|---|---|---|
| fbcca | LOSO | 82.40 |
| lda | LOSO | 87.61 |
| lda_subjnorm (offline upper bound) | LOSO | 90.03 |
| within_lda | within-subject | 90.79 |
| ccnn (seed 42; three-seed range 85.36–86.58) | LOSO | 86.17 |
| eegnet (sweep network; three-seed range 78.58–79.76) | LOSO | 79.76 |

The `within_lda` rows are within-subject. Their `Data source` text in the CSV still reads "LOSO" (a labelling defect, W-1, carried). For lda, LOSO is strictly below the matched within-subject reference for S01, S02 and S05 in the common set (z −2.74, −2.56, −2.68 SE_Δ). Warm-up (`reports/loso_warmup/cohort.csv`): warm-up minus no normalization is −25.03 pp at K = 1 and −16.95 pp at K = 2; at K = 10 the means are 88.19 % (none), 89.78 % (warm-up) and 90.69 % (whole session).

**Result, cohort 39** (S01–S040 without S020; separate data source; `reports/loso_w1_all/summary.csv`, `reports/loso_w1/summary.csv`): `all` (eight channels, 32 matched subjects) fbcca 75.80, lda 83.42, lda_subjnorm 86.13. `common` (POz, PO4, O1: three channels, not comparable with cohort 5) fbcca 64.56, lda 72.54, lda_subjnorm 75.16. For lda, LOSO against within on this cohort: **direction not observed** (22 of 32 subjects at or below within + 1 pp; mean 85.67 against 86.51).

**Open questions.** Whether the S05 difference between warm-up and whole-session normalization at K = 10 (−2.16 SE_Δ) has a mechanism. The LOSO networks on cohort 39 were limited by Sebastian (ccnn 39 folds, eegnet 2 of 39 folds not reported, compact_eegnet not run). The Colab notebook has not been run on a T4 GPU (human run).

## 9. GNN under LOSO (P23)

**Question.** Does the edge-gated connectivity graph network generalize across subjects, and how does it compare with the within-subject GNN and with lda?

**What was done.** The P15 edge-gated GNN was trained under LOSO and within subject on the same windows and channels (common, 7 channels), three seeds per fold. Labels: `pooled` (z-scored on training windows, R2) and `_subjnorm` (test-time normalization, offline upper bound).

**Result, cohort S01–S05, 1.0 s, three-seed ensemble** (`reports/loso_gnn/summary.csv`, `reports/within_gnn/summary.csv`):

| Variant | LOSO pooled | LOSO subject normalization | Within subject |
|---|---|---|---|
| nodes + F | 89.22 | 90.32 | 86.81 |
| nodes + coh + F | 88.96 | 90.29 | 86.98 |

Classical references on the same channels: lda 87.61, lda_subjnorm 90.03, within_lda 90.79. Predictions: PR-2 is missed for nodes + F, which is above lda on S02 (+4.66 pp, SE_Δ 2.28) and on S05 (+2.06 pp, SE_Δ 0.77); the wording is "GNN ≥ lda on S02/S05", never "beats". For the GNN, "LOSO below within" is **direction not observed** (LOSO 89.22 against within 86.81).

**PF-30 readings.** No fold is near chance (lowest test accuracy 70.15 % LOSO and 68.38 % within; chance 20 %). LOSO S01 and S02 show train-test gaps of 13.8–27.8 pp (a generalization problem); LOSO S03–S05 test accuracy is above train by 1.4–5.6 pp.

**Open questions.** The within-subject GNN reached the 150-epoch cap in 19 of 50 folds (a stated limitation; no epochs were tuned). The S02 2.0 s GNN cell in P15 is an accepted deviation (B007, cause not established). No online or first-K GNN claim is made.

## 10. Connectivity, the gate and the within-subject GNN (P12–P15)

**Question (P12–P13).** Does coherence depend on the estimator, and are connectivity deltas stable across subjects and permutations?

**Result (P12–P13).** Per-window coherence averaged over windows is biased upward: on synthetic independent noise 0.3373 per window, 0.0180 concatenated (`reports/connectivity/coherence_bias_demo.csv`). The baseline matched to the stimulus band lowers the broadband baseline in every cell (S03 0.6836 → 0.5871; S04 0.7291 → 0.6589). Cohort FDR totals (`reports/connectivity_cohort_summary.csv`): coherence 0 / 0 / 64 / 49 / 12; wPLI 4 / 0 / 42 / 28 / 5 (S01–S05). The reference totals of the original (R-12) are 0 / 0 / 65 / 51 / 15 and 0 / 3 / 38 / 33 / 18. The S05 wPLI total is an accepted deviation.

**Question (P14).** Are the cross-frequency differences only SSVEP power or alpha blocking?

**Result (P14, `reports/connectivity_comparison/`).** Coherence similarity across frequencies, Fisher mean r 0.629 (R-13: 0.54); coherence is largely explained by SNR (R² 0.675); no consistent in-alpha difference for coherence, PLV or wPLI (3 of 5 subjects each).

**Question (P15).** Do edge features add to node power and FBCCA features (the gate), and does a GNN help?

**Result (P15, `reports/connectivity_gate_benchmark.csv`, `reports/gnn_benchmark.csv`).** Base 73.75 %, Base + Ec 77.57 % (cohort means computed for this report from the k = 0 rows). The gate does not pass: no responder gains at least 2 pp (S03 +1.22, S04 +0.10, S05 −1.70). Within-subject GNN: the reference is reproduced on 11 of 12 subject cells; one cell (nodes + F, S02 at 2.0 s, 37.07 % against 46.1 %) is an accepted deviation (B007).

**Open questions.** The S05 pattern of coherence and PLV below baseline with wPLI above (exploratory, five subjects). The train-accuracy gap to the original (device or random-number stream; not testable here).
